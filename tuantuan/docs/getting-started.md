# 团团已安装：完成第一次连接

先按项目 README 启动电脑端服务，并通过官方 System Update 安装团团1.0.1。随后完成以下连接步骤。

1. 在团团屏幕上点击右下角“设置”。再点击“重新配网 / 设置服务器”。热点名称和密码会显示在屏幕上，配网窗口开放10分钟。更新固件后热点密码会改变，请以当前屏幕为准。
2. 用电脑或手机连接屏幕显示的 `Tuantuan-xxxx` 热点，在浏览器打开 `http://192.168.4.1`。
3. 填写家中 Wi-Fi 名称及密码。语音服务地址填写 `http://<电脑局域网IP>:8765`。连接口令填写本机 `server/config.env` 中 `DEVICE_TOKEN=` 等号后面的内容；不要使用 `DEEPSEEK_API_KEY`，也不要把密码或口令发到聊天里。
4. 点击“保存并重启团团”。将电脑切回家中网络，保持电脑端服务运行。设备和电脑必须能通过同一个局域网互相访问。
5. 等屏幕右上角变为“在线”，点击“开始说话”，说“你好呀，陪我聊一会儿”，再点一次结束录音。团团应当识别并用扬声器回答。
6. 再说“两分钟后提醒我喝水”，确认任务保存并等待屏幕和语音提醒。任务页可以完成、删除或稍后10分钟提醒。

如果右上角一直“离线”，先查看设置页的 Wi-Fi 状态，并检查电脑端服务是否仍在8765端口运行。电脑的局域网地址改变后，需要重新设置语音服务地址。

若设置页显示 Wi-Fi 已连接、时间正常，但服务日志显示 `401 GET /v1/state`，需要重新配网并填写正确连接口令：复制 `config.env` 中 `DEVICE_TOKEN=` 等号后面的完整值，不包含 `DEVICE_TOKEN=` 前缀、引号或额外空格。该口令与 DeepSeek API Key 是两个不同的值。正常连接的日志为 `200 GET /v1/state`。

电脑首次部署、服务启动与完整说明见 README.md。仓库仅提供配置模板，API Key 和连接口令填写到本机 `server/config.env`，该文件不会被 Git 跟踪。
