# 摄像头扫码修复 1.0.3（2026-10-16）

设备报告“未能打开摄像头”，旧版把分配、模块识别、格式和启动错误合并为同一提示，未保存到足够的初始化阶段信息，因此不能仅凭该提示认定接线问题。

本轮改动：

- 显式选择 BSP 的 OV3640、SC101IOT 均支持的 UYVY 1280×720，避免继承不匹配的默认尺寸/像素格式组合。
- 按初始化阶段记录错误，显示错误码及模块识别结果；保持严格模块描述校验，不启用未识别模块旁路。
- 注册标准 USB 触控接口，用同一个实际 UI 复现打开、返回和重新扫码。接口仅接受 USB 会话及屏幕范围内的指针输入，不记录字段内容。
- 记录首帧到达以区分“采集启动”和“真实取帧”；日志不输出二维码内容。
- 本机二维码改用白色背景，保持静区，避免透明背景影响对比度。
